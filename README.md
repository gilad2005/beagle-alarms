# שעוני ביגל

אפליקציה לאנדרואיד. מעתיקים את הודעת חלוקת המשימות בוואטסאפ ופותחים את האפליקציה.
ההודעה מודבקת לבד, מוצגת רשימת השעונים, ולחיצה אחת על "קבע שעונים" קובעת אותם.

- כל שעון נקרא על שם המשימה (למשל "מוריס", "פגאני").
- בריקוד קצר השעון נקבע חצי שעה לפני. אפשר לשנות בהגדרות.
- בשורה עם שתי שעות נלקחת המוקדמת.

## בנייה ב-GitHub

כל שינוי בקוד מפעיל בנייה בלשונית **Actions**. כשהיא מסתיימת, מורידים את `beagle-alarms-apk` מהחלק Artifacts ומתקינים את `app-debug.apk`.

האפליקציה לא מוחקת שעונים קיימים. אם קובעים פעמיים את אותם שעונים, ייווצרו שעונים כפולים.
