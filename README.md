# שעוני ביגל

אפליקציה לאנדרואיד. משתפים אליה את הודעת חלוקת המשימות, והיא קובעת שעון מעורר לכל שורה של "ביגל".
בריקוד קצר השעון נקבע חצי שעה לפני.

## איך בונים את ה-APK ב-GitHub

1. נכנסים ל-github.com ויוצרים repository חדש (פרטי או ציבורי, בלי README).
2. מעלים אליו את כל התוכן של התיקייה הזאת, כולל התיקייה `.github` (מחשב: גוררים את הקבצים לדף "uploading an existing file").
3. נכנסים ללשונית **Actions**. הבנייה מתחילה לבד אחרי ההעלאה ולוקחת כמה דקות.
4. כשהיא מסתיימת (וי ירוק), לוחצים עליה ומורידים את `beagle-alarms-apk` מהחלק Artifacts.
5. פותחים את ה-zip, מעבירים את `app-debug.apk` לטלפון ומתקינים. בטלפון מאשרים "התקנה ממקורות לא ידועים" כשהוא מבקש.

## שימוש

- בוואטסאפ: לוחצים לחיצה ארוכה על ההודעה, "שתף", ובוחרים "שעוני ביגל".
- או פותחים את האפליקציה, מדביקים את ההודעה ולוחצים "קבע שעונים".

האפליקציה לא מוחקת שעונים קיימים. אם מריצים אותה פעמיים על אותה הודעה, ייווצרו שעונים כפולים.
