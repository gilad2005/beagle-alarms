# שעוני משמרות

אפליקציה לאנדרואיד. מעתיקים הודעת חלוקת משימות ופותחים את האפליקציה.
ההודעה מודבקת לבד, מוצגת רשימת השעונים, ולחיצה אחת על "קבע שעונים" קובעת אותם.

- בהגדרות מקלידים את השם (או כמה שמות, מופרדים בפסיק). השורות עם השם מסומנות בהודעה.
- כל שעון נקרא על שם המשימה (הכותרת בין כוכביות, למשל `*מוריס*`).
- אפשר להגדיר כמה דקות לפני לכל השעונים, ושעון מוקדם יותר למשימות מסוימות (שורה לכל משימה: `שם = דקות`).
- בשורה עם כמה שעות נלקחת המוקדמת.
- ההגדרות נשמרות בין פתיחות.

## בנייה ב-GitHub

כל שינוי בקוד מפעיל בנייה בלשונית **Actions**. כשהיא מסתיימת, מורידים את `beagle-alarms-apk` מהחלק Artifacts ומתקינים את `app-debug.apk`.

האפליקציה לא מוחקת שעונים קיימים. אם קובעים פעמיים את אותם שעונים, ייווצרו שעונים כפולים.
